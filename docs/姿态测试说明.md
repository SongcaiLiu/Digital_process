# 姿态诊断记录说明

该工具用于记录不同头部姿态下的RGB、对齐深度、关键点、分类结果和头姿角，便于定位漏检与误检。它不改变真人规则，也不训练模型。

## 开始记录

关闭 RealSense Viewer 及其他占用相机的程序，在 `digital_process` 环境执行：

```powershell
python live_rgbd_system.py --record-test
```

用数字键标记当前测试段：

1. 正视
2. 左右转头
3. 低头和抬头
4. 转头与低头/抬头组合
5. 照片

每段建议持续10～15秒，按 `Q` 正常退出并等待报告生成。

## 输出内容

数据保存在 `demo_results/pose_tests/时间戳/`：

- `metadata.json`：相机内参、深度比例、配置和检测后端；
- `frames.csv`：逐帧人工段标签、分类、诊断、角度和动作状态；
- `samples/*.npz`：抽样保存的原始BGR、对齐深度、关键点和检测框；
- `report.md`：各测试段的统计；
- `recording_status.json`：后台写盘及丢帧状态。

重新生成报告：

```powershell
python analyze_pose_test.py "demo_results/pose_tests/具体时间戳"
```

人工数字标签只表示当时执行的测试内容，不是精确姿态真值。录制时应保持相机位置不变，并分别测试正面、侧脸、不同距离和照片。
